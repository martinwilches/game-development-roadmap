## Game Design Document

Es un documento que describe que se quiere construir, como funcionara y que experiencia se quiere ofrecer.

```
PROJECT TITLE

1. General information

- Name: Project Shadow Escape
- Genre: 2D Top-Down Survival
- Platform: Windows PC
- Engine: Godot 4.x
- Programming language: GDScript
- Perspective: Top-Down
- Resolution target: 1280x720
- Players: Single Player

2. Game Concept

The player wakes up in an abandoned forest.
The objective is to collect resources, avoid enemies
and escape before the timer reaches zero.

3. Core Gameplay Loop

1. Explore the environment.
2. Collect resources.
3. Avoid enemies.
4. Find the exit.
5. Complete the level.
6. Unlock the next challenge.

4. Main Mechanics

- Player movement
- Enemy detection
- Health system
- Collectible objects
- Timer
- Scoring system
- Level progression

5. Characters

Player:
- Health: 100
- Movement: Four directions
- Abilities: Run, collect objects, avoid enemies

Enemies:
- Basic enemy
- Fast enemy
- Boss enemy

6. Game Systems

- Input System
- Combat System
- Inventory System
- Enemy AI
- Level Manager
- Save System
- UI System

7. Art Direction

- 2D pixel art
- Dark atmosphere
- Forest environment
- Night setting

8. Audio Direction

- Ambient forest sounds
- Background music
- Footsteps
- Combat effects

9. Development Scope

Version 1:
- One playable character
- One level
- Two enemy types
- Basic combat
- Health and timer
- Victory and defeat screens

10. Future Features

- Procedural levels
- Advanced enemy AI
- Dynamic missions
- AI-powered NPC dialogue
- Additional environments

```
